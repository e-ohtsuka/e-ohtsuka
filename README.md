# Python Portfolio

Pythonによる業務改善・デスクトップツールの制作記録です。

## 技術・開発の進め方

- **言語・GUI**：Python、Tkinter／ttk
- **ファイル・データ処理**：JSON、CSV、ファイル操作
- **画像・PDF処理**：Pillow、PyMuPDF（休業日カレンダー作成ツール）
- **テスト・ソース管理**：`unittest`、Git、GitHub
- **生成AIの活用**：仕様検討、実装支援、テスト・ドキュメント整備。動作や画面を確認しながら改良しています。

各リポジトリには、ソースコード、操作説明、画面見本を掲載しています。実装内容やテストの範囲については、それぞれのREADMEを参照してください。

Pythonを用いた業務改善、ツール開発、DX推進に関わる開発業務に取り組みたいと考えています。
